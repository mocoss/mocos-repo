# 便捷聊天浮窗

作者：**Mocos**

适用于特定越狱环境的微信内部聊天辅助插件，提供会话快捷访问与本地消息提醒界面。

> **重要提示：本项目由第三方独立开发，与腾讯、微信及其关联主体不存在隶属、合作、授权、赞助或背书关系。免责声明不能替代合法授权，也不能免除依法应承担的责任。若相关功能或分发方式不符合适用法律、平台规则或第三方权利要求，应停止使用或分发。**

## 项目状态

- 目标微信版本：**8.0.54**。
- 提供 **rootless** 与 **RootHide** 两种独立软件包，请按实际环境选择，不要混装。
- 当前提供的 1.0.2 重点调整自定义图片持久化；长时间后台及过夜恢复仍需验证。版本记录不代表对其他设备、系统或微信版本的兼容承诺。
- 本项目不是腾讯或微信官方功能，也不是微信客户端的官方替代品。

## 功能概览

- 微信内部可拖动的聊天浮窗。
- 展示首页会话，支持搜索及快捷进入聊天。
- 新消息头像提醒，支持持续或限时闪烁。
- 在已匹配的接口范围内过滤免打扰及折叠会话提醒。
- 可调整左右手模式、尺寸、闲置不透明度及默认图标。
- 不注入 SpringBoard，不主动修改微信桌面角标。

所有功能均依赖实际运行环境，第三方接口变化可能造成失效、异常或与微信真实状态不一致。

### 本插件的数据处理说明

按当前发布实现：

- 插件在微信进程内读取实现会话列表、头像提醒及聊天跳转所需的数据。
- 设置及缩小后的自定义图片保存在微信本地应用数据目录；备份也位于该应用数据范围内，不属于异地备份。
- 插件未设计向维护者服务器发送联系人名单、聊天正文或自定义图片的功能，也未加入独立遥测或广告分析模块。
