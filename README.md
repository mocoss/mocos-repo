# 便捷聊天浮窗 1.0.0
作者：Mocos

## 本次变更
- 设置按「启用 / 消息提醒 / 外观与布局 / 工具 / 关于」分组。
- 系统分组背景、统一字体、动作行蓝色强调、分组说明与多行文本。
- 持续闪烁开关与限时时长放在同组，版本与作者移到末尾。
- 滑动条固定在单元格内部，避免说明文字与滑条重叠。
- 配置只读访问直接使用内存缓存，不再分配可变字典。
- 移除已停用的全量联系人解析代码与消息回调中的方法枚举。
- 正常列表加载后释放临时诊断文本；手动复制诊断时才枚举接口。
- 每次已读同步复用本轮会话管理器，避免逐项重复获取服务。
- 保留前台2秒轮询与0.4秒容差；后台停止浮窗计时器及动画、清理图片缓存；后台消息只排队，不更新浮窗UI。
- 继续保留有界头像缓存与自定义图标缓存。
- 以优化体积参数编译，并清理未使用的链接段。

## 版本与兼容范围
两个包版本均为1.0.0，包ID保持 local.minis.wechatfloat，可从0.1.x覆盖升级，沿用微信沙盒中的设置与图片。
- rootless：iphoneos-arm64，/var/jb布局。
- RootHide：iphoneos-arm64e包标记、ARM64二进制、RootHide原生安装名与布局，不需手动转换。
- 仅注入 com.tencent.xin 微信主程序，不注入SpringBoard，不修改微信或桌面角标。
- 目标微信8.0.54。历史版本已在用户的XR/iOS15.6/Dopamine与15 Plus/RootHide环境逐步验证；1.0.0新设置界面与精简改动只做了构建/静态检查，公开发布前需用户回归测试。

## 发布前建议检查
1. 两种环境覆盖安装、重新打开微信，收纳设置入口存在且旧设置保留。
2. 五组设置可见，3种滑动条完整，浅色/深色模式均可读。
3. 免打扰私聊/群与折叠群不闪烁；普通会话显示头像、可跳转。
4. 从微信原列表读消息后浮窗提醒可清除；持续与限时模式分别正常。
5. 切后台再返回、长按隐藏、闲置贴边及透明度正常。
6. 相册选图、恢复图标、关闭再开启正常。
7. CocoaTop同场景比较前后台占用。没有经过量化测试，不应宣称固定省电比例或内存降幅。

## 已知边界
依赖微信私有接口，不保证其他微信版本适配。限时动画在前台恢复或新消息/设置刷新后可能重新计时。插件提醒队列不是微信真实未读数据库。使用越狱插件无法保证账号零风险。
